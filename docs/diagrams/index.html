revagent 다이어그램

순서대로 보면 입력·출력 → 루프 동작 → 한 스텝의 내부 → run의 상태 변화를 따라갈 수 있습니다. 저장소에는 archify 소스 JSON(0N-*.json)만 두고, 탐색 가능한 HTML 뷰(각 ~800 KB, 대부분 동일한 내장 뷰어)는 필요할 때 archify로 다시 생성합니다: 이 폴더에서 archify 스킬에 해당 JSON을 넘기면 같은 이름의 .html이 나옵니다.

  1. 1. 전체 구조 (아키텍처)사용자 입력, .secure, CLI, Docker 샌드박스, Agent 루프, 도구 9개, vLLM(Qwen), case.md와 산출물이 어디에 있고 무엇을 주고받는지.
  2. 2. 에이전트 루프 (워크플로우)작업 메시지 → Qwen 스텝 → 도구 실행 → 진행 판정. 관찰 원장 [obs], 비평가 [critic], 압축이 끼어드는 지점과 submit_flag / handoff_runbook 종료 경로.
  3. 3. run_gui 한 스텝 (시퀀스)모델 호출, wine·Xvfb 위의 실행과 입력·캡처, 원장 기록, 12k 잘림과 [env] 푸터, 다음 스텝까지의 메시지 순서.
  4. 4. run 라이프사이클 (상태)시작 → 스텝 반복 → 제출 검증 → solved → 기록. 압축·축소 같은 중간 상태와 runbook / unsolved / error 종료 상태.
생성: archify · 링크는 소스 JSON(0N-*.json)이며, HTML 뷰는 커밋하지 않고 필요할 때 archify로 재생성합니다. 뷰어 UI 문구는 영어(한국어 로케일 미지원), 다이어그램 내용은 한국어.
